USB-Erstinstallation

TeeNet per USB installieren

Board auswählen, per USB anschließen und in Chrome oder Edge installieren.

TeeNetESP32-S3 N16R8 · 16 MB Flash

Vorbereiten

  1. Chrome oder Edge am Computer verwenden.
  2. Den ESP über ein USB-Datenkabel anschließen.
  3. Andere Programme schließen, die den USB-/COM-Port verwenden.
Der ESP wird nicht erkannt?

BOOT halten, RST kurz drücken, BOOT loslassen und erneut verbinden. Sonst Datenkabel, USB-Port und gegebenenfalls USB-Treiber prüfen.

Installieren

Erstinstallation löscht vorhandene Daten.
WLAN, Einstellungen und Aufzeichnungen auf dem gewählten ESP gehen verloren. Für ein bereits eingerichtetes TeeNet das OTA-Update verwenden.

Erprobte Standardhardware mit 16 MB Flash.

Nach den Bestätigungen „ESP verbinden“ wählen, den USB-/COM-Port auswählen und im Dialog installieren.
